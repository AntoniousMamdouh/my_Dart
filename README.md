# 🚀 Dart Learning Journey

Welcome to my Dart programming learning repository! This repository contains my practical code snippets, exercises, and topic-by-topic explorations as I master the **Dart** programming language for cross-platform development.

---

## 📂 Repository Structure

The code is organized into topic-specific files to make reviewing concepts straightforward:

| File Name | Topic Covered | Concepts Demonstrated |
| :--- | :--- | :--- |
| `main.dart` | **General Dart Setup** | Entry point, printing output, basic variables & syntax. |
| `dotOperator.dart` | **Operators & Accessors** | Property access, method cascades (`..`), null-aware operators (`?.`, `??`). |
| `array.dart` | **Collections** | Lists (arrays), Sets, and Maps (Data structures & manipulation). |
| `loop.dart` | **Control Flow & Loops** | `for`, `for-in`, `while`, `do-while`, `forEach`, and iteration strategies. |

---

## 🛠️ How to Run the Code

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AntoniousMamdouh/my_Dart
   cd my_Dart
   ```

2. **Run any specific topic file using Dart SDK:**
   ```bash
   dart run path/to/file.dart
   ```
   *(Example: `dart run loop.dart`)*
